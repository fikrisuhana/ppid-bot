# 🏛️ PPID Bot Purbalingga

Sistem Chatbot Cerdas Pelayanan Informasi Publik untuk PPID Kabupaten Purbalingga. Dilengkapi dengan mitigasi overuse token, arsitektur RAG, widget responsif, dan integrasi Live Chat.

## 📂 Struktur Repositori

- `backend-ai/`: Server AI backend berbasis Python FastAPI & knowledge retrieval.
- `wordpress-plugin/`: Plugin WordPress untuk embedding widget & proxy REST API.
- `frontend-widget/`: Widget UI standalone (HTML/CSS/JS) untuk demo & integrasi mandiri.
- `docs/`: Dokumentasi arsitektur, instalasi, dan dataset FAQ.
